   004 | Feature: GRF004 - Valid EPSG prefix in coordinate reference system
   005 | The rule verifies that if the name of a CRS starts with "EPSG:", it must refer to a valid coordinate reference system code from the official EPSG geodetic parameter dataset,
   006 | and that if the geodetic datum or vertical datum starts with "EPSG:", it must identify a datum of the matching kind (reference frame or datum ensemble)
   007 | or a geographic / vertical CRS that is defined on such a datum. Datums given by name are accepted when the name matches an EPSG datum or CRS of the matching kind exactly,
   008 | or is a geodetic datum key of the CS-MAP catalogue. A name of a datum of the other kind is an error; other names are not checked.
   009 | EPSG code validation is performed using the pyproj library, which includes a local copy of the official EPSG dataset (https://epsg.org) maintained by IOGP.
   010 | For reference: https://pyproj4.github.io/pyproj/stable/api/database.html
