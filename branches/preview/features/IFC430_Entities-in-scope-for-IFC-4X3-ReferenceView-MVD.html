IFC430 Entities in scope for IFC 4X3 ReferenceView MVD - v1

001 | @IFC
002 | @version1
003 | @industry-practice
004 | Feature: IFC430 - Entities in scope for IFC 4X3 ReferenceView MVD
005 |
006 | The rule verifies that IFC models using schema version 4.3 and declaring the Reference View Model View Definition (MVD)
007 | do not export any entities that are outside the scope of this MVD.
008 |
009 |   Scenario Outline: Check for in-scope entities - IFC4.3 ReferenceView
010 |
011 |     Given A model with Schema 'IFC4.3'
012 |     Given A model with Model View Definition 'ReferenceView'
013 |     Given An IFC model
014 |
015 |     Then There must be less than 1 instance(s) of .<Entity>. ^excluding subtypes^
