   004 | Feature: GRF007 - Valid vertical datum CRS type
   005 | The rule verifies that a vertical datum given as an EPSG code identifies a vertical datum (reference frame or datum ensemble),
   006 | or a vertical CRS that is defined on one, to ensure valid height referencing. A datum given by name is accepted when the name
   007 | matches an EPSG vertical datum or vertical CRS exactly; the name or CS-MAP key of a geodetic datum is an error; other names are not checked.
   008 | https://pyproj4.github.io/pyproj/stable/api/crs/crs.html
   009 | https://pyproj4.github.io/pyproj/stable/api/crs/datum.html
